# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text is at that address and applies to all project spaces: issues, pull requests, discussions and reviews.

In short: be respectful, accept feedback gracefully, focus on what is best for the project, and do not harass anyone.

## Reporting

To report behavior that breaks the code of conduct, contact the maintainer through GitHub: open a private report from the repository's Security tab (Report a vulnerability, and say it is a conduct report), or message [@VA24d](https://github.com/VA24d). Reports are handled privately. The maintainer can warn, edit or remove comments, or block people from the repository, following the enforcement ladder in the Covenant.
